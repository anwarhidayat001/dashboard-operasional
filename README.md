# CeisMon Android
Cara build APK (tanpa install Android Studio):
1. Buat repo GitHub, upload semua isi folder ini, push.
2. Tab Actions -> "Build APK" -> download artifact `CeisMon-apk` (app-debug.apk).
Atau buka folder di Android Studio -> Build > Build APK(s).
Catatan: HP harus bisa akses host customs.go.id (VPN/jaringan kantor bila perlu).
